Mockup 1 · Harbour Home

Answer "is my data OK, and if not, what do I click?" in one screen.
  1. Five destinations, not 17 tabs. Home, Build, Data, Observe, Ship in an icon rail. Sub-tabs like Sentinel, Quality, Diff become filters inside Observe instead of siblings you have to remember. The rail becomes a bottom bar on phones.
  2. Omnibox is the nav. The existing ⌘K palette gets promoted to the top bar and searches objects (models, tables, runs), not just commands.
  3. Environment is a loud pill. Green for dev, red outline for prod, so you always know where Run lands.
  4. Four numbers that matter, each with its own "why" line underneath.
  5. Needs attention is a work queue. Failed assertions, Sentinel anomalies, late sources and broken contracts merged into one ranked list, each with the next action inline.
  6. Run history at a glance. Height = duration, red = failed. Spikes and failures jump out without opening Runs.
  7. Layers as a flow. landing → bronze → silver → gold with freshness on every model. Failing chips link straight to the Build workbench.
