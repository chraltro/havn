Quick Start

Running in under a minute

Terminal 
# Install havn
$ pip install havn

# Scaffold a new project
$ havn init my-project
$ cd my-project

# Run the full pipeline
$ havn stream full-refresh

# Start the web UI
$ havn serve
# → http://localhost:3000

Four commands to a working pipeline

  • 1 Install from PyPI with a single pip command. No system dependencies beyond Python 3.10+.
  • 2 Scaffold a project with ingest, transform, and export directories plus a project.yml config.
  • 3 Run the full pipeline — ingest scripts pull data, SQL transforms build the warehouse layer by layer.
  • 4 Explore your data in the browser with the built-in web UI, query runner, and DAG visualizer.
Install

Choose your path

PyPI for local development, Docker for isolated or production deployments.

PyPI

Install with pip. Python 3.10+ required.

pip install havn # Start a project havn init my-project cd my-project havn serve

Docker

Run in a container. No Python install needed.

docker run -v $(pwd):/project \ -p 3000:3000 \ ghcr.io/chraltro/havn serve
