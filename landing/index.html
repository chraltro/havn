// what
Three building blocks
engine

DuckDB

Embedded OLAP analytics in a single file. No servers, no clusters.

transforms

Plain SQL

Standard SQL with dependency comments. Automatic DAG ordering, change detection.

pipeline

Python

Ingest and export with plain scripts. Connectors for databases, APIs, files.

// everything
One platform, zero glue

Ingestion through monitoring - every stage of the data lifecycle in a single tool. No stitching together five services. Access everything from the web UI or the CLI.

Ingest
Python scripts + 10 built-in connectors pull data into landing
havn ingest · havn connect
Transform
SQL DAG with change detection, incremental builds, schema evolution
havn transform
Export
Push results to APIs, databases, or files with plain Python
havn export
Lint
SQLFluff integration catches style and syntax issues before they ship
havn lint --fix
Test & Quality
Inline assertions, YAML contracts, anomaly detection on every run
-- assert: · contracts/
Monitor
Run history, freshness checks, schema sentinel, Slack alerts
havn history · alerts
Version Control
Full git workflow from the web UI - commit, branch, diff, push
git panel · havn diff
CI/CD
Auto-generate GitHub Actions, data diff PR comments on every push
havn ci generate
>_ CLI
◇ Web UI

// how
Four commands
terminal 
# install
pip install havn

# scaffold
havn init my-project && cd my-project

# run pipeline
havn stream full-refresh
  bronze.raw_orders       done  0.2s
  silver.fct_orders       done  0.6s
  gold.revenue_daily      done  0.4s
  ✓ 3 models built in 1.2s

# serve UI
havn serve
  • http://localhost:3000
  • 01
    InstallOne pip command. Python 3.10+ only.
  • 02
    ScaffoldCreates ingest/, transform/, export/ with project.yml.
  • 03
    RunIngest pulls data, SQL transforms build landing through gold.
  • 04
    ExploreBrowse tables, query data, visualize DAG in the web UI.
