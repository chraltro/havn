Engine

DuckDB

Blazing-fast OLAP analytics in a single embedded file. No servers, no clusters.

Transforms

Plain SQL

Write standard SQL with dependency comments. Automatic DAG ordering with change detection.

Pipeline

Python

Ingest and export with plain Python scripts. Pre-built connectors for databases, APIs, and files.

Up and running in four commands

From install to a live web dashboard — under a minute.

# Install from PyPI
pip install havn

# Create a new project
havn init my-project
cd my-project

# Run the full pipeline
havn stream full-refresh

# Open the web UI
havn serve
# → http://localhost:3000
  • 1

    Install

    One pip command. No system dependencies beyond Python 3.10+.

  • 2

    Scaffold

    Creates ingest, transform, and export directories with a project.yml config.

  • 3

    Run

    Ingest scripts pull data, SQL transforms build the warehouse — landing through gold.

  • 4

    Explore

    Browse tables, run queries, and visualize the DAG in the built-in web UI.
